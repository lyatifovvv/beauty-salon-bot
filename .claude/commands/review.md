## Задача

Делегируй:
1. **`@reviewer`** — проверит соответствие кода `docs/core/MATH_MODEL.md`

Каждый создаст свой отчёт (`REVIEW.md` и `SECURITY_REVIEW.md`).

После обоих — **дай пользователю сводку простыми словами:**


Если есть блокеры (❌) — предложи: «Хочешь я сразу всё исправлю?» (через `@reviewer` для нарушений мат-модели, через `/dev` для багов кода).
