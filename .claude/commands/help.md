## Задача

Пользователь запутался — нужно простыми словами сказать «вот где ты сейчас, вот что делать дальше».

## Алгоритм

На основе pre-flight статуса определи **текущий шаг** и **следующее действие**:

| Что есть | Где ты | Что дальше |
|---|---|---|
| Ничего | В самом начале | `/start` или сразу `/brief` |
| Бриф | Идея описана | `/math` — детальное ТЗ |
| Мат-модель без валидации | ТЗ готово | `/validate` — проверить |
| Валидация ДА | ТЗ проверено | `/architect` — выбрать стек |
| TECH_STACK | Стек выбран | Купить VPS Beget + заполнить .env + `/dev` |
| Код есть, нет деплоя | Локально работает | `/deploy` |
| Деплой был | На проде | `/dev` дальше или `@reviewer` для изменений |

Покажи **одним абзацем** где пользователь сейчас и **одной командой** что дальше.

## Формат ответа

```
📍 Ты здесь: <короткое описание состояния>

Сделано:
  ✅ <пункт>
  ✅ <пункт>

Следующий шаг: <одна команда>

Это займёт <~N минут>. Готов?
```

## Если что-то непонятно

Если пользователь пишет «не работает», «сломалось», «ошибка» — **передай управление `@friendly-troubleshooter`**, не пытайся диагностировать сам.

Если пользователь хочет что-то изменить в готовом проекте — направь на `@reviewer`.
