## Принцип: блоки + сразу деплой

После каждого блока пользователь видит результат **на своём сайте в интернете**.

### Этап 1. План (только Режим A)

Разбей реализацию на блоки от простого к сложному:
1. **Скелет + БД + страница "Hello"** (после этого — первичный `/deploy`)
2. Главные сценарии — каждый отдельным блоком
3. Внешние интеграции — каждая отдельно
4. Уведомления, админка, полировка

**Используй TodoWrite** для списка блоков. Покажи план. Скажи:

> Перед каждым блоком прошу включить plan mode (Shift+Tab дважды). Я покажу план, ты утверждаешь, потом пишу код и сразу деплою.

Жди «ОК».

### Этап 2. Блок 1 — Скелет + первичный деплой

1. Папки, package.json/pyproject.toml, .gitignore, git init.
2. Простейшая главная страница / `/start` для бота: «Привет, [проект] здесь!».
3. **Для веб-проекта:** вызови `@design-engineer` чтобы сделал красивую страницу с самого начала. Не дефолтную пустую.
4. Подключение к БД, миграция базовых таблиц.
5. Локальный запуск, проверка curl/браузером.
6. Скажи: **«Блок 1 готов локально. Запускаем первичный деплой. Переключи `/permissions` → `bypass permissions`, потом вызови `/deploy`».**

После `/deploy` → переход к Этапу 3.

### Этап 3. Каждый следующий блок

1. **Plan mode.** «Перед блоком N включи plan mode — Shift+Tab дважды».
2. **План.** Какие файлы создам/изменю, какие функции из §X мат-модели реализую, какие тесты добавлю.
3. **Ожидание утверждения.**
4. **Реализация** по `CLAUDE.md`. Для дизайн-задач — `@design-engineer`. Для авторизации — `@security-guard` проверит после.
5. **Самопроверка по мат-модели** — чек-лист ✅/⚠️/❌.
6. **Тесты:** линтер + тесты через Bash. Падает → чини до зелёного.
7. **Локальная проверка** через curl или попроси пользователя.
8. **Коммит:** Conventional Commits.
9. **Деплой:**
   ```bash
   git push origin main
   sshpass -p "$BEGET_VPS_PASSWORD" ssh root@$BEGET_VPS_IP \
     "cd /root/app && git pull && [install deps if changed] && [migrations if any] && systemctl restart myapp"
   ```
10. **Проверка прод:** `curl -I https://$BEGET_DOMAIN`.
11. **Отчёт:** «✅ Блок N выкачен. На сервере: `<URL>`. Локально работает, тесты зелёные, прод отвечает. Готов к блоку N+1?»
12. Обнови TodoWrite (completed).
13. **Жди ответ.**

## Защитные правила

- **Тесты не проходят:** не деплой сломанное. Останови.
- **Деплой упал:** откати: `git revert HEAD && git push && ssh ... systemctl restart`.
- **Противоречие в мат-модели:** останови, «В §X: A, в §Y: B, что выбираем?».
- **Пользователь хочет изменить логику посреди блока:** STOP. «Это новое изменение — нужно обновить мат-модель через @reviewer».
