# GLOSSARY.md — Термины проекта

> Один термин — одно понятие — один тип. Claude должен использовать именно эти слова.
>
> Заполняется автоматически агентом `/math` по мере сбора мат-модели.

## Бизнес-термины

(Пример — заменишь под свой проект)

- **Клиент** (`Client`) — человек, который зарегистрировался в системе. Имеет имя и телефон.
- **Гость** (`Guest`) — посетитель который не зарегистрировался (не оставил имя+телефон). Не может записаться.
- **Запись** (`Appointment`) — конкретное событие: клиент пришёл к мастеру на услугу в конкретное время.
- **Услуга** (`Service`) — то, что салон оказывает (маникюр, массаж, и т.п.) с длительностью и ценой.
- **Мастер** (`Master`) — сотрудник, делает услуги.

## Технические термины

- **Слот** — конкретное время доступное для записи к мастеру на услугу.
- **Бэкап** — резервная копия данных. Делается ежедневно.

## Что НЕ путать

- Запись (Appointment) ≠ Бронь — у нас только Запись.
- Клиент ≠ Гость — Гость ещё не зарегистрировался.
- Мастер ≠ Администратор — Мастер делает услуги, Администратор управляет.
