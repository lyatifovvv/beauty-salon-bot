# Interactive Master-Service Assignment for Salon Admins

## Context and Problem Statement

В текущей версии бота «Sebastian» администратор видит список услуг каждого мастера, но не имеет возможности добавлять новые или отвязывать старые услуги от мастера через интерфейс Telegram-бота. 

## Decision Drivers

* Удобство интерфейса: привязка и отвязка услуг должна выполняться в 1 клик с помощью интерактивных кнопок без ввода текста.
* Мгновенный фидбек: состояние привязки каждой услуги (привязана/не привязана) должно отображаться визуально (например, с помощью символов ✅ и ❌).
* Сохранение инвариантов бизнес-логики: бот должен по-прежнему предлагать клиентам только тех мастеров, которые умеют делать выбранную услугу.

## Proposed Changes

* В карточку мастера в админке добавить кнопку «💅 Изменить услуги мастера».
* При клике на нее выводить список всех услуг салона в виде inline-кнопок. Услуги, которые делает мастер, помечать символом `✅`. Услуги, которые он не делает, помечать символом `❌` (или оставлять без галочки).
* Реализовать переключение (toggle) связи между мастером и услугой по клику на соответствующую inline-кнопку с мгновенным обновлением сообщения.

## Decision Outcome

Chosen option: Добавить интерактивное переключение услуг мастера через inline-клавиатуру в `/admin`.
