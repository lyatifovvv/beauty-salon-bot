# Allow Admin to Manage Services and Edit Appointments (Rescheduling)

## Context and Problem Statement

В текущей версии бота «Sebastian» администратор не может управлять каталогом услуг (добавлять, изменять цену/длительность/название) и изменять данные существующих записей клиентов (переносить на другую дату/время). Также требуется проверить надежность изменения данных клиентов администратором.

## Decision Drivers

* Безопасность: доступ к операциям только при наличии сессии `AdminSession` (инвариант I10).
* Сохранение инварианта I1 (без наложений при переносе записи).
* Удобный интерфейс: выбор новой даты и времени для переноса записи через встроенную клавиатуру слотов.

## Proposed Changes to MATH_MODEL.md

### Раздел 4 «Инварианты»:
* Любое изменение времени записи (`startsAt`) должно проходить ту же валидацию наложений (I1), рабочих часов (I3) и доступности мастера (I2), что и создание новой записи.

### Раздел 5 «Сценарии / Операции»:
* Добавить операцию переноса записи администратором: `rescheduleAppointment(appointmentId, newStartsAtLocal)`.
* Добавить операции добавления и редактирования услуг: `createService(name, duration, price)`, `updateService(id, data)`.

## Decision Outcome

Chosen option: Добавить в панель администратора `/admin` разделы для управления услугами и переноса записей, с валидацией перекрытий слотов в реальном времени.

### Consequences

* **Good:** Полная гибкость администрирования салона (услуги и записи можно менять без ручного редактирования БД).
* **Bad:** Увеличение сложности интерфейса за счет многошагового процесса переноса записи (выбор новой даты/времени для существующей записи).
