# Редактирование расписания на месте (Single Message UI) для чистоты чата

## Context and Problem Statement

При настройке рабочих часов мастера по дням недели бот отправлял новые сообщения через `sendNewPrompt`. Из-за этого старое сообщение карточки мастера (`adm_v_m`) со старым расписанием оставалось выше в истории чата в неизменном виде, что вводило администратора в заблуждение.
Необходимо сделать так, чтобы все изменения расписания в реальном времени отображались в едином сообщении-карточке, а при завершении настройки карточка мастера обновлялась с актуальными рабочими часами.

## Decision Drivers

* **Инвариант I13 (Чистота чата):** Минимизация количества сообщений в чате, исключение дублирования устаревших карточек.
* **Наглядность изменений:** Отображение полного расписания на неделю непосредственно внутри меню настройки дней недели.

## Proposed Changes

1. **Редактирование сообщений на месте:**
   - Заменить использование `sendNewPrompt` на `editMessageText` во всех интерактивных callback-обработчиках настройки рабочих часов (`workingHours`, `adm_wh_d`, `adm_wh_s`).
2. **Отображение полного расписания в меню настройки:**
   - Создать функцию `renderWorkingHoursDaysMenu`, которая выводит список дней недели для выбора и текущее расписание мастера на неделю.
   - Использовать эту функцию при входе в настройку часов и после каждого изменения дня недели.
3. **Обновление при текстовом вводе:**
   - При переходе к ручному вводу времени (`adm_wh_c`) сохранять в сессии `whCardMessageId` текущего интерактивного сообщения.
   - После успешного текстового ввода обновлять исходное интерактивное сообщение карточки по его `message_id` через `api.editMessageText`, возвращая его в актуальное состояние меню дней недели.

## Consequences

* **Положительные:** В чате администратора всегда находится ровно одно актуальное сообщение. Исключается путаница с устаревшим временем работы в истории чата. Полное расписание наглядно обновляется в реальном времени прямо перед глазами администратора при кликах на кнопки.
* **Отрицательные:** Нет.
