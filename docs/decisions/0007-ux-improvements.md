# Комплексные улучшения UX (Отмена записей, Загрузка фото, Расписание)

## Context and Problem Statement

По результатам UX-аудита (проведенного в роли Senior UX Researcher) были выявлены 7 критических точек трения в пользовательском опыте:
1. Запись отменяется в один клик без подтверждения.
2. Для фото мастера требуется вводить URL текстом, что сложно с телефона.
3. Расписание мастера настраивается путем ввода JSON-строки.
4. В календаре показываются даты, на которые нет свободных слотов.
5. Отсутствие кнопок «Отмена» в тупиковых сценариях ввода текста.
6. Отсутствие информации о мастере при выборе опции «Любой свободный мастер».
7. Разрыв сценария после ввода имени нового мастера в админке.

## Decision Drivers

* **Удобство для мобильных устройств:** все действия должны совершаться кликами или нативными функциями мессенджера (например, отправка фото), а не вводом сложного текста/форматов.
* **Предотвращение ошибок:** защита деструктивных действий (отмена записи) и валидация пустых списков.
* **Бесшовный опыт:** отсутствие тупиков (dead ends) и непрерывность сценариев (создание мастера -> его настройка).

## Proposed Changes

1. **Защита от случайной отмены:** Добавить промежуточный шаг с кнопками `[Да, отменить]` и `[Нет, оставить]` при попытке отмены.
2. **Загрузка фото:** Настроить обработчик `bot.on('message:photo')`, который будет извлекать `file_id` максимального размера из сообщения Telegram и сохранять его в поле `photoUrl`. Telegram поддерживает отправку изображений по `file_id`.
3. **Интерактивные рабочие часы:** Вместо ручного ввода JSON внедрить меню с выбором дней недели, а затем меню с шаблонами часов (10:00-19:00 и т.д.) или выходным днем.
4. **Фильтрация дат:** Вызывать `getAvailableSlots()` для каждого из 14 генерируемых дней при формировании календаря. Скрывать даты без доступных слотов (или помечать ❌).
5. **Escape hatches (Отмена):** Добавить inline-кнопку «❌ Отмена» под каждым сообщением-prompt-ом (которое запрашивает текст).
6. **Прозрачность подбора:** После автоматического выбора мастера (при нажатии "Любой") запрашивать из БД его имя и добавлять в текст сообщения "Свободные слоты у мастера: {имя}".
7. **Бесшовное создание:** После успешного выполнения `createMaster` автоматически перенаправлять на карточку `adm_v_m:{id}` вместо главного меню.

## Consequences

* **Положительные:** Полностью устраняются барьеры для администраторов и клиентов. Улучшается качество продукта без изменения архитектуры и схемы БД.
* **Отрицательные:** Небольшое увеличение количества inline-кнопок и обработчиков, а также увеличение запросов к БД при рендере календаря (14 быстрых запросов к локальной SQLite).
