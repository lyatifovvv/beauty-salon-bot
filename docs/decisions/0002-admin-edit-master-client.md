# Allow Admin to Edit Master and Client Data

## Context and Problem Statement

Администратору салона «Sebastian» необходима возможность изменять данные клиентов (например, имя, телефон, статус блокировки) и мастеров (имя, фото, рабочие часы, услуги) напрямую через панель администратора в Telegram-боте. Это важно для исправления ошибок при регистрации клиентов или изменения информации о мастерах.

## Decision Drivers

* Безопасность данных: изменять информацию о клиентах и мастерах может только авторизованный администратор (наличие активной сессии `AdminSession`).
* Сохранение ссылочной целостности: изменение данных о клиенте или мастере не должно ломать существующие записи (`Appointment`).
* Простота интерфейса: редактирование должно выполняться через пошаговые сценарии в Telegram-боте.

## Proposed Changes to MATH_MODEL.md

### В раздел 1.4 «Панель администратора» (в брифе) и раздел 4 «Инварианты»:
* Разрешить операцию изменения имени (`name`) и телефона (`phone`) клиента администратором с валидацией инварианта **I6** (формат телефона) и **I8** (уникальность Telegram ID / телефона).
* Добавить возможность блокировки/разблокировки клиента администратором (изменение флага `is_blocked`).
* Добавить явную операцию редактирования полей мастера: имя (`name`), фото (`photo_url`), список услуг (`service_ids`) и расписание (`working_hours`).

## Decision Outcome

Chosen option: Добавить в функционал `/admin` сценарии для редактирования полей мастеров и клиентов, с валидацией вводимых данных на уровне бизнес-логики бота.

### Consequences

* **Good:** Полный контроль администратора над базой данных клиентов и мастеров для оперативного исправления ошибок.
* **Bad:** Увеличение сложности интерфейса админки (добавление дополнительных меню и шагов для редактирования).
