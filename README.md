# 👋 Привет

Это шаблон для запуска твоего проекта (сайт / бот / лендинг). Технику делает AI, ты только отвечаешь на вопросы.

К концу — твой проект работает в интернете.

---

## 1. Один раз поставь инструменты

Если **уже стоят** (VS Code открывается, Claude Code установлен) → переходи к шагу 2.

1. **VS Code** — скачай с `code.visualstudio.com`
2. **Node.js LTS** — скачай с `nodejs.org`
3. Открой Terminal (Mac) или PowerShell (Win), выполни:
   ```
   npm install -g @anthropic-ai/claude-code
   ```
4. В VS Code → иконка Extensions слева → поиск «Claude Code» → ставь от Anthropic
5. Оплати **Claude Pro** ($20/мес) на `claude.ai`
6. В терминале: `claude login` → войди в браузере

---

## 2. Подготовь папку

1. Эту папку (где ты сейчас читаешь) **переименуй** под свой проект, например `my-salon`
2. Перенеси в удобное место, например `~/projects/my-salon/`
3. Открой её в VS Code: **File → Open Folder**

---

## 3. Запусти Claude Code

1. Нажми **Cmd+Esc** (Mac) или **Ctrl+Esc** (Win) — внизу появится панель Claude Code
2. Набери и нажми Enter:
   ```
   /start
   ```

✅ Дальше Claude сам ведёт тебя за руку.

---

## ⛔ Одно правило на всё

Когда захочешь что-то изменить — **не пиши «измени код»**. Пиши:

```
@reviewer хочу <что хочу>
```

Это страховка от хаоса. Подробности — в `docs/core/WORKFLOW_RULES.md`.

---

## 🆘 Если запутался

Просто напиши Claude в чат:

```
/help
```

Или своими словами: «не работает», «непонятно что делать», «как мне X». Claude разберётся.
