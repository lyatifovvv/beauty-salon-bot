# PROJECT_BRIEF.md — Sebastian

## 1. Название проекта

**Sebastian** — Telegram-бот для онлайн-записи и автоматизации бьюти-салона.

## 2. Одно предложение

Telegram-бот для клиентов салона красоты «Sebastian», позволяющий быстро записаться к мастерам, управлять своими визитами и получать напоминания, а также администрировать расписание и услуги через встроенную панель администратора.

## 3. Для кого

- **Клиенты салона** (преимущественно женщины), которые ценят время, активно пользуются Telegram и хотят записываться онлайн в любое время суток без звонков.
- **Владелец и администраторы салона**, которым нужен простой инструмент для контроля расписания, управления услугами/мастерами и удержания клиентов без сложного ПО.

## 4. Какую боль решаем

- **Для клиентов:** необходимость звонить или писать сообщения в мессенджерах, долгое ожидание ответа администратора для подтверждения записи.
- **Для салона:** рутинные задачи по записи клиентов, пропущенные звонки, забывчивость клиентов (неявка), сложность оперативного заполнения «горящих окошек» при отменах.

## 5. Функционал первой версии (MVP)

### 1. Онлайн-запись (для клиентов)
- Выбор услуги (из категорий с ценой и длительностью).
- Выбор мастера (с фото, описанием или вариант «Любой свободный»).
- Интерактивный календарь с реальным расписанием мастеров и выбором даты/времени.
- Автоматическое подтверждение записи без участия администратора.
- Гибкая архитектура (адаптер) для возможности легкого подключения внешних CRM (YCLIENTS, DIKIDI и др.) в будущем.

### 2. Личный кабинет клиента
- Просмотр активных (будущих) записей.
- Кнопка отмены записи (с ограничением по времени, например, не позже чем за 3 часа до начала).
- Возможность позвать администратора (уведомление администратору о запросе помощи).

### 3. Панель администратора (команда `/admin` для доверенных лиц)
- Управление мастерами (добавление, удаление, редактирование профиля, фото, расписания).
- Управление клиентами (просмотр профилей, редактирование имени/телефона, блокировка/разблокировка).
- Управление услугами (категории, название, цена, длительность).
- Управление расписанием мастеров (настройка рабочих дней и слотов времени).
- Просмотр списка записей на сегодня/ближайшие дни.

### 4. Сервис и напоминания
- Автоматические напоминания о визите за 24 часа и за 2 часа до процедуры с кнопками подтверждения/переноса.
- Сбор отзывов: оценка мастера (1–5) через 2 часа после визита.
  - Оценка 5: предложение оставить отзыв на картах (Яндекс, Google, 2ГИС) со ссылкой.
  - Оценка ≤ 3: прямая отправка отзыва администратору салона для оперативного решения.

### 5. Информационный блок
- Раздел «Как добраться» (карта, текстовое описание, ориентиры).
- Прайс-лист и портфолио мастеров.
- Правила подготовки к процедурам.

## 6. Что НЕ делаем в первой версии

- Онлайн-оплата (оплата производится на месте в салоне).
- Реферальная система и сложные маркетинговые рассылки («горящие окошки», автоматический бонусный баланс) — эти функции отложены для следующих версий.
- Полноценная интеграция с внешними CRM (создаем только интерфейсы под них).

## 7. Стек технологий

- **Платформа:** Node.js + TypeScript + библиотека Grammy (для разработки Telegram-бота).
- **БД:** PostgreSQL 16 (хранение мастеров, услуг, расписания, клиентов и записей).
- **Сервер:** VPS (Ubuntu 24.04 LTS) на Beget с Nginx в качестве прокси.
